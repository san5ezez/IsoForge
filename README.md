# UltraISO Studio x64 (Windows 64-bit)

Полнофункциональное десктопное приложение для **Windows x64** на базе C# / .NET 8 (Windows Forms), реализующее создание, редактирование, конвертацию, монтирование и запись самозагружаемых ISO-образов с автоматической сборкой готового автономного `.exe` через **GitHub Actions**.

## Архитектура и реализованные функции

### 1. Главное меню (Верхняя строка)
* **Файл (`File`)**:
  * Создать новый образ (`Ctrl+N`), Открыть образ (`Ctrl+O`), Сохранить (`Ctrl+S`), Сохранить как (`Ctrl+Shift+S`).
  * **Свойства (`Alt+Enter`)**: настройка файловой системы образа (**ISO 9660**, **Joliet** для длинных и русских имен в кодировке UCS-2, **UDF Bridge** для чтения файлов размером более 4 ГБ), метки тома (`Volume Label`), издателя и идентификатора системы.
* **Действие (`Action`)**:
  * Создание новых папок внутри ISO (`F7`), добавление файлов (`F3`) и папок с ПК, извлечение из образа (`F4`), переименование файлов и папок (`F2`), удаление (`Del`).
  * **Атрибуты (`Ctrl+A`)**: управление атрибутами файлов и папок внутри образа (**Скрытый / Hidden**, **Только чтение / Read-Only**, **Системный / System**, **Архивный / Archive**) и датой/временем записи.
* **Самозагрузка (`Bootable`)**:
  * **Записать образ Жесткого диска (`Write Disk Image`, `Ctrl+B`)**: запись загрузочного ISO-образа на USB-флешку (режимы `USB-HDD+`, `USB-HDD`, `USB-ZIP+`, `USB-ZIP`, а также сохранение посекторного `.img`).
  * **Загрузить / Извлечь загрузочный файл (`Load / Extract Boot File`)**: извлечение загрузочного сектора El Torito (`.bif`, `.bin`, `.img`) из существующего диска и вшивание его в другой образ для превращения обычного образа в самозагружаемый, плюс генератор стандартного 2048-байтного загрузчика El Torito x86/x64.
* **Инструменты (`Tools`)**:
  * Монтирование и размонтирование ISO-образа в виртуальный привод Windows (`ISODrive` / `Mount-DiskImage`, `F6`).
  * Снятие ISO-образа с реального физического CD/DVD/USB-привода (`F8`).
  * Запись образа на оптическую CD/DVD-болванку (`F9`).
  * Сжатие в формат `.ISZ` и конвертация форматов (`.MDF`, `.NRG`, `.IMG`, `.BIN` -> `.ISO`).
  * Вычисление и проверка контрольных сумм файлов (**CRC32**, **MD5**, **SHA-1**, **SHA-256**).
* **Опции (`Options`)**:
  * Настройка виртуального привода (`ISODrive` — буква привода, количество приводов, автомонтирование).
  * Регистрация файловых ассоциаций (`.iso`, `.isz`, `.mdf`, `.nrg`, `.img`, `.bin`) и интеграция в контекстное меню Проводника Windows (`HKCU\Software\Classes`) для монтирования и записи по клику правой кнопкой мыши без требования прав администратора.

### 2. Панель инструментов (Иконки быстрого доступа — 3 блока)
* **Блок файлов**: `Создать` (Чистый лист) -> `Открыть` (Папка) -> `Сохранить` (Дискета) -> `Сохр. как`.
* **Блок сборки**: `Добавить` (Папка с плюсом — отправляет выбранные файлы/папки с ПК в образ) -> `Извлечь` (Папка с минусом — вытаскивает файлы из образа на ПК).
* **Блок работы с носителями**:
  * `Сделать ISO` (Диск с дисководом — снятие ISO с физического привода/флешки).
  * `Записать CD` (Диск с огнем — запись на CD/DVD-болванку).
  * `Привод` (Диск с шестеренкой — монтирование в виртуальный дисковод).
  * `Сжать ISZ` (Диск с тисками — сжатие в формат `.ISZ`).
  * `Конвертер` (Два диска — конвертер из `MDF`, `NRG`, `IMG`, `BIN` в `ISO`).

### 3. Рабочая область (4 Окна + Drag-and-Drop)
* **Верхняя половина (Ваш ISO-образ)**:
  * **Окно 1 (Верхнее левое — Дерево образа)**: иерархия папок внутри открытого образа во главе с корнем диска (меткой тома).
  * **Окно 2 (Верхнее правое — Содержимое образа)**: файлы и подпапки выбранной директории образа с размером, датой и атрибутами.
* **Нижняя половина (Ваш компьютер)**:
  * **Окно 3 (Нижнее левое — Дерево ПК)**: локальные диски (`C:`, `D:`, USB-флешки) и дерево папок.
  * **Окно 4 (Нижнее правое — Локальные файлы)**: файлы и папки выбранного каталога ПК.
* **Drag-and-Drop**: перетаскивание мышью файлов и папок снизу вверх (из Окна 4 в Окно 2, а также напрямую из Проводника Windows) добавляет их в образ; перетаскивание сверху вниз (из Окна 2 в Окно 4) извлекает данные из ISO на ПК.

### 4. Строка состояния и Индикатор объема (Самый низ окна)
* Слева отображается полный путь к текущей папке внутри образа, количество файлов и папок, а также статус загрузчика (`Самозагружаемый` / `Несамозагружаемый`).
* Графическая шкала заполненности показывает итоговый объем образа в МБ или ГБ и меняет цвет на красный при переполнении.
* Выпадающий список носителей (`CD 700MB`, `DVD 4.7GB`, `DVD 8.5GB (DL)`, `Blu-Ray 25GB`, `USB Flash 64GB`) автоматически пересчитывает шкалу и выводит предупреждение, если образ не помещается на выбранную болванку.

## Сборка на GitHub Actions (Windows x64)

1. Создайте новый репозиторий на GitHub и загрузите в него содержимое архива `UltraISOStudio-win64-github-repo.zip`.
2. При каждом `push` в ветку `main`/`master` или ручном запуске во вкладке **Actions** (`Build Windows x64 Application`) автоматически запускается workflow `.github/workflows/build-win64.yml` на виртуальной машине `windows-latest`.
3. Workflow компилирует автономный 64-битный исполняемый файл `UltraISOStudio.exe` (не требующий установки .NET на целевом ПК), прогоняет встроенный автотест движка (`--self-test`) и публикует готовый артефакт `UltraISOStudio-Windows-x64` (`UltraISOStudio.exe` и `UltraISOStudio-win-x64.zip`).
